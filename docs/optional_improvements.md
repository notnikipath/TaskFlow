# Опциональные улучшения

Реализовано 6 улучшений:

1. **A1** Автоматическая оценка сроков задач.
2. **A2** Рекомендации по исполнителям.
3. **A3** Детекция выгорания сотрудников.
4. **B2** Интеграция с Git (`/integrations/git/webhook`).
5. **B3** Slack/Telegram bot subscriptions и publish.
6. **C1 + C2** Параллельный расчёт Ганта и кэширование досок.

Дополнительно:

- Настраиваемые дашборды по ролям (`analytics-service`).
- Светлая/тёмная тема во фронтенде.
