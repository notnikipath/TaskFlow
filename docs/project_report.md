# Project Report

## 1. Цель

Создать масштабируемую платформу управления проектами и задачами с предиктивной аналитикой, контролем рисков и автоназначением исполнителей.

## 2. Реализация обязательной части

- Полный цикл управления:
  - проект -> задача -> распределение -> уведомление -> аналитика -> отчётность.
- Многопользовательский режим:
  - роли, RBAC, аудит.
- Масштабируемость:
  - микросервисы, асинхронная коммуникация по HTTP, инфраструктурный стек в docker-compose.

## 3. Метрики

- Board load target: `< 2 сек` (отражается в board API и KPI).
- Forecast target: `MAPE < 10%` (метрика и endpoint `/analytics/mape`).
- Планируемая поддержка: `5000 concurrent users` (KPI target + горизонтальное масштабирование сервисов).

## 4. Риски и меры

- Перегрузка сервиса уведомлений: очереди RabbitMQ и масштабирование.
- Неверные прогнозы: постоянный контроль MAPE и ручная корректировка.
- Человеческий фактор распределения: автоназначение + ручной override.

## 5. Что подготовлено к сдаче

- Исходный код с Dockerfile для каждого сервиса.
- `docker-compose.yml`.
- Тесты: unit/integration/load.
- CI/CD workflow.
- Документация архитектуры, API, развёртывания, алгоритмов.
- Набор демо-данных 12 000 задач.

## 6. План развития

- Продвинутая ML-модель прогноза сроков на исторических данных.
- Продвинутые боты с интерактивными командами.
- Мобильное приложение для команды.
- Интеграции Jira/Trello/Calendar.
